📚 使用指南
完整打包流程

    打开 PyPacker → 看到首页 5 个功能卡片
    
    基本设置
    
        入口脚本：选择你要打包的 .py 文件
        
        程序名称：自动填充为脚本名，可修改
        
        输出目录：留空则在脚本旁生成 dist/
    
    打包模式：
    
        单文件 --onefile：适合小工具，只有一个 exe
        
        文件夹 --onedir：适合大项目，启动快（推荐）
        
        构建选项：按需勾选 --console / --clean / --noconfirm
    
    图标
    
        源图片：选一张 PNG / JPG
        
        缩放方式：一般用「居中裁剪铺满」
        
        手动裁剪：需要特殊构图时用
        
        勾选「把图标嵌入目标程序」：让窗口和任务栏图标也变成你选的图
    
    版本信息（仅 Windows）
    
        填写文件版本、产品版本、公司名称、版权信息等
        
        打包后右键 exe → 属性 → 详细信息，能看到这些内容
